# 🪔 Bappa Mandap Challenge

A festive browser-based game created for the **Ganesh Chaturthi Game Design Contest**.

## 🎮 About the Game

**Bappa Mandap Challenge** is a time-based decoration game where players decorate a Ganesh mandap using different festive decorations.

Players have **60 seconds** to create a creative and balanced mandap, complete challenges, earn points, and achieve the highest possible score.

## 🕹️ How to Play

1. Open the game and click **Begin Decorating**.
2. Use the available decorations to decorate the mandap.
3. Complete the challenges that appear during the game.
4. Try to create a creative and balanced decoration.
5. Finish your decoration before the timer runs out.
6. View your final score, rating, and decoration results.

## ✨ Features

- 60-second decorating challenge
- Interactive mandap decoration
- Challenge-based gameplay
- Creativity and decoration scoring
- Best-score tracking
- Final score and star rating
- Festive Ganesh Chaturthi theme
- Interactive 3D-style environment
- Admire Mandap mode
